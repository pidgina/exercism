# Exercism: Go

[Exercism](https://exercism.org/) для трека **Go**.

Каждое задание находится в отдельной ветке, которую автоматически
создаёт сервис синхронизации решений. В таблице ниже приведено краткое
описание задач и прямые ссылки на исходный код.
